Idle Restaurant Tycoon 0.3.0

Installable free-family testing candidate. The normal Android build succeeded with zero errors. No purchases or advertising. Phone performance and child usability acceptance remain pending; this is not a store-approved release.

Game and balance

Read the complete active family game guide and the active 40-outlet balance export. Edit FamilyBalance.asset for family tuning and RestaurantCatalog.asset for content, art and audio slots. Keep IDs and array lengths stable when replacing assets; changing the content count needs a save migration.

The first service teaches one action at a time. Guests queue, order, collect food, reserve chairs, sit, eat and return their plates. Green upgrades are affordable; grey NEED cards need coins; SOON cards unlock through the guide. Stars keep upgrades and coins, and can be earned every five further services after maxing the local upgrades. Teammates train with earned tickets. Goal books roll forward. There is no energy, daily ticket cap or guest patience penalty.

The progression model opens all 40 outlets in about 353 minutes for its stated strategy. That is an analytical forecast, not a measured full playthrough. Continued play develops these finite outlets through service, stars, goals and teammates.

Editable project

Open Assets/Restaurant/Production/RestaurantGame.unity in Unity 6000.3.26f1. Mouse, keyboard and touch use the same UI. Editor keys: 1/2/3 buy visible cards, M opens the map and Esc goes back. Use Restaurant → Family Game for the economy forecast, first-service test, menu test and busy-service tests. The content workbench also inspects tuning and provides development funds/max-level controls.

Asset replacement instructions cover the food/environment slots, character rig and animations, materials, audio, UI and editor tools. Runtime furniture has colliders; replacement furniture must preserve clear lanes and seat approach geometry. Keep food renderers separate from plates for portion animation.

Remaining acceptance

  • Install and play on representative Android 11+ midrange phones. Check real touch, safe areas, suspend/resume, saves, at least a 30-minute session, frame time, memory and thermal behavior.
  • Have a ten-year-old complete onboarding without verbal help; confirm they recognize affordable upgrades and find the next restaurant.
  • Prepare publisher signing/AAB, review the store icon/listing and complete the current store declarations. Ads and billing accounts are not needed for this edition.
  • This test build disables generated C++ debug information to keep build output compact. Restore symbolicated release diagnostics when preparing public distribution.

The Editor retains a development state from the play-mode checks. Automatic review blocked an optional final reset of that profile to protect saved progress. No Android-device save was accessed. New APK installs begin with the tutorial. Recruitment skips owned teammates and stops spending tickets when the team is complete.

No intentionally temporary visual/audio placeholders remain in this pass. The original procedural assets are the selected base style. Historical reference specifications and 0.2.0 footage remain labeled separately. Source history is in mahnul-playnoob/idle-restaurant, branch main.
