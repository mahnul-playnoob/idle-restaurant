Fixed regression

The first new exit route cut diagonally toward the exit and could hit a doorway post. The live test caught the stalled service. Customers now align with the doorway before passing through it. The successful rerun and long session use this corrected route. The initial failed test is retained in the evidence.

Android package smoke test — PASS

The v0.5.3 APK installed and ran in an Android 15 ARM64 emulator. Actual Android taps completed onboarding upgrades and Map navigation, called a visible janitor and reached its payment/cooldown. Relaunch retained service progress, upgrade levels and cooldown. No crash, shader or save error matched the process-filtered smoke log. Emulator verification does not establish physical-phone performance or Android 11 runtime behavior.

Limits and release blockers

  • Android package is debug-signed; Play Store release signing is not configured.
  • No physical Android phone was available for this verification; midrange Android 11+ performance remains unverified.
  • Coverage includes early progression and focused cleanup flows, not a full 40-restaurant endurance playthrough.
  • Cleanup reward is fixed at dispatch; new dirt created during a visit belongs to the next batch. Seating remains automatic.
  • No new temporary visual placeholders were introduced. People, outfits and cleaning props are original editable stylized geometry; final visual approval remains the user’s decision.
